# Refining

`instagraal.refine` joins whole contigs from the contacts next to their ends,
places the short ones, recentres circular scaffolds, and scores the joins of
a layout, as `instagraal-refine` does. `run_refine` runs it all; the other
functions are its steps. See [Refining the scaffolds](../guides/refine.md).

::: instagraal.refine
